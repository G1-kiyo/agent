## AI辩论功能详细结构

### 在消息中的AI辩论触发

```
单个消息 (MessageItem)
├── 消息头部
├── 消息内容
├── 操作按钮组
│   ├── 回复按钮
│   ├── 反应按钮
│   ├── 分叉按钮 ← 新增
│   └── AI辩论按钮 ← 新增
├── 回复区域（可选）
└── 子回复列表（可选）
```

### AI辩论生成过程

```
AI辩论生成逻辑
1. 用户点击某条消息的"AI辩论"按钮
2. 弹出辩论设置对话框
   ├── 选择辩论风格（均衡/批判/实用/理论）
   ├── 设置辩论角色（支持方/反对方）
   └── 确认辩论主题（基于原消息内容）
3. 生成辩论内容
   ├── 分析原消息观点
   ├── 生成支持方观点
   ├── 生成反对方观点
   └── 添加相关论据和例子
4. 在消息列表中插入辩论消息
   ├── 作为原消息的回复
   ├── 标记为AI生成内容
   ├── 角色标识（支持方/反对方）
   └── 特殊样式区分
```

### 分叉功能改进

```
分叉功能
1. 用户点击某条消息的"分叉"按钮
2. 弹出分叉对话框
   ├── 分叉标题（基于原消息内容）
   ├── 分叉描述（可选）
   ├── 标签选择（可选）
   └── 隐私设置（可选）
3. 创建新的讨论分支
   ├── 原消息作为新讨论的起始消息
   ├── 保留原讨论的上下文
   ├── 创建新的讨论ID
   └── 在历史话题中显示
```
