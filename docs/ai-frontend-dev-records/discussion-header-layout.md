# 讨论头部组件布局设计文档

## 最终布局结构

```
┌─────────────────────────────────────────────────────────────┐
│                      标题区域（最终版）                     │
│  讨论标题                                      [统计卡片区域] │
│  进行中  🏷️ 分类                                       │
│                                            📊123 📊456 📊789 │
│                                            浏览量 消息数 回复数│
└─────────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────────┐
│                        详细信息区域                        │
│  发起人: 用户名                                                │
│  📅 创建时间: 2024-01-01                                      │
│  👥 参与者: 10人                                               │
│  🔄 最后活跃: 2小时前                                          │
└─────────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────────┐
│                         描述区域                            │
│  这里是讨论的详细描述内容...                               │
└─────────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────────┐
│                        标签区域                            │
│  [标签1] [标签2] [标签3] ...                               │
└─────────────────────────────────────────────────────────────┘
```

## 详细说明

### 1. 标题区域
- **讨论标题**：单独一行，左对齐，大字体（28px）
- **状态和分类信息**：第二行，左对齐
  - 状态徽章（进行中/已结束/已归档）
  - 分类标签（技术/产品等）
- **统计卡片**：靠右对齐，小尺寸卡片
  - 浏览量卡片：123
  - 消息数卡片：456
  - 回复数卡片：789
  - 每个卡片格式：上面数字，下面小label

### 2. 详细信息区域
- 每个信息单独一行展示
- 发起人一行
- 创建时间一行
- 参与者一行
- 最后活跃一行

### 3. 描述区域
- 讨论的详细描述文本
- 字体适中，行距舒适

### 4. 标签区域
- 各种话题标签
- 横向排列，可换行

## 设计原则

1. **简洁明了**：重要信息一目了然
2. **层次分明**：通过布局和样式区分信息重要性
3. **响应式设计**：适配不同屏幕尺寸
4. **视觉平衡**：左侧信息区，右侧统计区，保持视觉平衡

## 关键CSS类说明

- `.discussion-header`：主容器
- `.title-section`：标题区域（包含标题、状态、统计）
- `.topic-title`：讨论标题
- `.status-badge`：状态徽章
- `.category-badge`：分类标签
- `.stats-container`：统计卡片容器（靠右）
- `.stat-card`：单个统计卡片
- `.detail-section`：详细信息区域
- `.info-item`：单个信息项（每行一个）

## 响应式设计

- 大屏幕：保持左右布局
- 中等屏幕：统计卡片可能换行
- 小屏幕：所有元素垂直排列

## 删除的功能

- 移除了原有的action-buttons（📊🔗⭐按钮）
- 简化了统计展示方式

## 优化点

1. 统计卡片靠右展示，不占用主内容区域
2. 详细信息每行一个，更加清晰
3. 整体布局更加紧凑和实用
